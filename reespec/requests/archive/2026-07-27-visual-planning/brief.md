# Visual planning for reespec workflow

## Goals

Add `/visual-plan` and `/visual-recap` commands to the reespec workflow — lightweight visual planning that renders diagrams, wireframes, and review annotations inline in the chat. Built as a downstream consumer of the structured tool views system (request `structured-tool-views`).

## Non-goals

- Not adding a separate rendering engine or image-generation library (resvg, Sharp, etc.)
- Not replacing the existing reespec markdown artifacts (brief.md, design.md, specs, tasks.md remain the source of truth)
- Not adding a shared app backend or persistent plan storage (plans are generated per-request)
- Not changing the pi/ree agent loop

## Impact

Currently, the reespec workflow is purely text-based markdown. No visual output.

After this change:
- `/visual-plan` reads a reespec brief + design and outputs structured block data that renders as an inline diagram in WebChat
- `/visual-recap` reads completed tasks and renders a before/after visual summary
- Both are implemented as a skill file (agent instructions) + a `PlanView` React component that renders the structured blocks
- The same pattern works for any structured plan, not just reespec

## Discovery summary

Analysis of Agent-Native's Plans template showed it uses structured blocks (wireframe, diagram, annotated-code, decision, data-model, file-tree) with typed schemas, rendered inline in chat by React components. It does NOT use a server-side rendering engine — the LLM outputs structured data, the UI renders it.

This pattern is a direct consumer of the structured tool views system (request `structured-tool-views`). The `view` system provides the infrastructure for rich inline rendering; visual-planning adds specialized `view` types (`plan-block`, `wireframe`, `diagram`) on top.

No separate rendering engine needed. The component renders SVG inline from the structured data.

## Key design decisions (to confirm in plan phase)

- Implemented as a reeboot skill (`.md` file instructing the agent on structured output format)
- Plus one `PlanView` React component that renders structured plan blocks
- Block types (inspired by Agent-Native): `diagram` (nodes+edges), `wireframe` (component layout), `annotated-code` (file + line annotations), `decision` (choices + rationale), `file-tree` (project structure)
- Renders as SVG inline via the structured tool views system
- Text fallback for WhatsApp/Signal channels (SVG description generated by the agent)
- Depends on request `structured-tool-views` for the rendering infrastructure
